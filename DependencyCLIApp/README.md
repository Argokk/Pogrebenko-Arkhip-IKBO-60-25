# DependencyCLIApp

Визуализатор строит граф зависимостей Python-пакета обходом BFS и выводит
список связей в консоль. Поддерживаются PyPI JSON API и тестовый файл.
Дополнительные настройки находятся в `config.xml`.

Из этой папки запустите `sh run.sh config.xml`; для тестов выполните
`sh tests/run-tests.sh`. Нужна Java 11 или новее. Полное описание настроек
и ограничений находится в README в корне репозитория.
