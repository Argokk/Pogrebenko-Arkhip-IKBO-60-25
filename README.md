# Учебные проекты

В корне находится эмулятор командной строки на Java (нужна Java 14 или новее).
Для запуска графического интерфейса из корня репозитория выполните:

```bash
sh run.sh
```

Проверка эмулятора: `sh tests/run-tests.sh`. Дополнительные пути к CSV и
сценарию команд можно передать как первый и второй аргументы `run.sh`.

В папке `DependencyCLIApp` находится визуализатор зависимостей:

```bash
cd DependencyCLIApp
sh run.sh config.xml
sh tests/run-tests.sh
```

# Визуализатор графа зависимостей Python-пакетов

Программа получает информацию о зависимостях Python-пакета и строит
граф, учитывая как прямые, так и транзитивные зависимости.

Для получения информации о пакетах используется PyPI JSON API.
Программа обращается к репозиторию напрямую, без использования
менеджера пакетов pip и сторонних библиотек для получения зависимостей.

## Возможности

- Чтение настроек из XML-файла.
- Получение прямых зависимостей Python-пакета из PyPI.
- Построение графа зависимостей с помощью алгоритма BFS.
- Исключение пакетов по подстроке в имени.
- Обработка циклических зависимостей.
- Работа с тестовым репозиторием из текстового файла.
- Вывод графа зависимостей в консоль.

## Требования

Для запуска необходима Java версии 11 или новее.

Для работы с PyPI требуется подключение к интернету.

## Конфигурация

Настройки программы находятся в файле `config.xml`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<config>
    <packageName>requests</packageName>
    <repositoryUrl>https://pypi.org</repositoryUrl>
    <testRepositoryPath></testRepositoryPath>
    <testMode>false</testMode>
    <graphImageFile>dependencies.png</graphImageFile>
    <asciiTree>true</asciiTree>
    <packageFilter></packageFilter>
</config>
```

Описание параметров:

- `packageName` — имя анализируемого пакета.
- `repositoryUrl` — адрес репозитория с PyPI JSON API.
- `testRepositoryPath` — путь к файлу тестового репозитория.
- `testMode` — работа с тестовым репозиторием: `true` или `false`.
- `graphImageFile` — имя файла для будущего изображения графа.
- `asciiTree` — настройка будущего режима вывода ASCII-дерева.
- `packageFilter` — подстрока для исключения пакетов из графа.

Если `packageFilter` пустой, фильтрация не применяется. Если имя
исходного пакета содержит указанную подстроку, программа сообщит
об ошибке.

Параметры `graphImageFile` и `asciiTree` считываются и проверяются,
но создание изображения и вывод ASCII-дерева пока не реализованы.

## Запуск

Откройте терминал в папке `DependencyCLIApp` и выполните:

```bash
sh run.sh config.xml
```

Можно также скомпилировать и запустить программу вручную:

```bash
javac -d out src/*.java
java -cp out Main config.xml
```

Результат выводится в консоль. Каждая строка содержит пакет и список
его прямых зависимостей:

```text
A -> [B, C]
B -> [D]
C -> [D]
D -> []
```

## Тестовый репозиторий

Для работы без обращения к PyPI используется текстовый файл.
Каждая строка содержит имя пакета, двоеточие и его зависимости:

```text
A: B C
B: D
C: D
D: A
```

Имена пакетов должны состоять из заглавных латинских букв. Если у
пакета нет зависимостей, после двоеточия ничего не указывается:

```text
D:
```

Для включения тестового режима укажите в `config.xml`:

```xml
<packageName>A</packageName>
<testRepositoryPath>test-repository.txt</testRepositoryPath>
<testMode>true</testMode>
```

Путь к тестовому файлу задаётся относительно рабочей папки программы.

## Проверка

Для запуска проверочных сценариев выполните:

```bash
sh tests/run-tests.sh
```

Проверяются цепочка зависимостей, цикл, фильтрация и пакет без
зависимостей.

## Ограничения

Программа считывает зависимости из метаданных PyPI, но пока не
вычисляет условия окружения и не подбирает совместимые версии пакетов.
Для разбора JSON используется упрощённая собственная реализация.
